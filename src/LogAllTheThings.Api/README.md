# LogAllTheThings API

ASP.NET Core Web API for storing and retrieving timestamped log entries. Data is persisted in a local SQLite database.

## Prerequisites

- .NET 8 SDK

## Run

From the repository root:

```powershell
dotnet run --project .\src\LogAllTheThings.Api\LogAllTheThings.Api.csproj
```

The API listens on <http://localhost:5000>.

In the Development environment, Swagger UI is available at:

- <http://localhost:5000/swagger>

The repository's WPF launcher can also start the API and web frontend together:

```powershell
dotnet run --project .\tools\DevLauncher\DevLauncher.csproj
```

## Database

Entity Framework Core uses SQLite. Unless a `ConnectionStrings:LogsSqlite` value is provided, the API uses:

```text
Data Source=logs.db
```

The database and tables are created automatically at startup. A new database is seeded with these log types:

| ID | Name |
| --- | --- |
| 1 | Medicine |
| 2 | Food |
| 3 | Custom |

Delete `logs.db` while the API is stopped to reset local data.

## API

Base route: `/api/logs`

| Method | Route | Description |
| --- | --- | --- |
| `GET` | `/api/logs` | Return all entries, newest first |
| `GET` | `/api/logs/{id}` | Return one entry by GUID |
| `POST` | `/api/logs` | Create an entry |
| `DELETE` | `/api/logs/{id}` | Delete an entry |

### Create an entry

`Description` is required. `Id` is generated by the API, and `Timestamp` defaults to the current UTC time when omitted.

```powershell
$body = @{
    TypeId = 1
    Description = 'Morning medication'
    Details = '10 mg with food'
    Category = 'Daily'
} | ConvertTo-Json

Invoke-RestMethod `
    -Method Post `
    -Uri http://localhost:5000/api/logs `
    -ContentType 'application/json' `
    -Body $body
```

Example JSON payload:

```json
{
  "typeId": 1,
  "description": "Morning medication",
  "details": "10 mg with food",
  "category": "Daily",
  "customName": null
}
```

### List entries

```powershell
Invoke-RestMethod http://localhost:5000/api/logs
```

### Delete an entry

```powershell
Invoke-RestMethod `
    -Method Delete `
    -Uri http://localhost:5000/api/logs/00000000-0000-0000-0000-000000000000
```

Replace the example GUID with an existing entry ID.

## Configuration

Override the SQLite connection string with standard ASP.NET Core configuration. For example:

```powershell
$env:ConnectionStrings__LogsSqlite = 'Data Source=C:\data\logs.db'
dotnet run --project .\src\LogAllTheThings.Api\LogAllTheThings.Api.csproj
```

CORS currently permits any origin, header, and method. This is suitable for local development but should be restricted before exposing the API outside localhost.

## Build

```powershell
dotnet build .\src\LogAllTheThings.Api\LogAllTheThings.Api.csproj
```
